# Simple-Password-Generator 🔐

## About the Project
Advanced Password Generator is a Python-based desktop application developed using Tkinter. It allows users to generate strong and random passwords by selecting different character types and specifying the desired password length.

The application also provides a feature to copy the generated password directly to the clipboard.

## Features
- Generate Random Passwords
- Set Custom Password Length
- Include Uppercase Letters (A–Z)
- Include Lowercase Letters (a–z)
- Include Numbers (0–9)
- Include Special Symbols
- Password Length Validation
- Copy Generated Password to Clipboard
- Simple and User-Friendly GUI

## Technologies Used
- Python
- Tkinter (GUI Development)
- Random Module
- String Module
- Pyperclip (Clipboard Functionality)

## Installation

1. Install Python on your system.
2. Install the required library:

   ```bash
   pip install pyperclip
   ```

3. Save the source code as:

   ```bash
   password_generator.py
   ```

4. Run the application:

   ```bash
   python password_generator.py
   ```

## How It Works
1. Enter the desired password length.
2. Select the character types you want to include.
3. Click on the Generate Password button.
4. Your random password will be displayed.
5. Click Copy to Clipboard to copy the generated password.
